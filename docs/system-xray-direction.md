# System X-Ray direction

The portfolio is treated as an engineering publication rather than a generic developer landing page.

## Visual thesis

**Open the system. See how it works.**

- Grotesk-first typography; no decorative display serif.
- Monospace only for system metadata and technical readouts.
- One signal color for interaction and request tracing.
- Rules, alignment and whitespace instead of rounded cards.
- Motion communicates architecture or state changes instead of decorating text.
- Mobile layouts are recomposed rather than scaled-down desktop diagrams.

## Project presentation

Flagship systems use detailed engineering case studies. Private client work is presented through sanitized architecture, product behavior and technical decisions without exposing private source code, data, credentials or confidential prompts.
